# Installing the Joulescope UI

The Joulescope User Interface (UI) is the quickest and easiest way to use your
Joulescope.  It works with all Joulescope instruments.

(supported-platforms)=

## Supported platforms

<!-- The only place that lists operating system and Python versions.  Every
other page links here with {ref}`supported-platforms`. -->

The Joulescope software supports these 64-bit operating systems:

| Operating system | Supported versions |
|---|---|
| Microsoft® Windows® | Windows 11 |
| Apple® macOS® | macOS 26 and 27, Intel and Apple Silicon.  The Joulescope UI requires macOS 14 or newer. |
| Linux® | Ubuntu® 26.04 LTS.  Other distributions may work, but are not officially supported. |

To install the Joulescope software with pip, or to use the Python packages
such as `joulescope_driver` and `joulescope`, you need 64-bit Python 3.12 or
newer.

