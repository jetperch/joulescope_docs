# Joulescope JS220+ Datasheet

The Joulescope™ JS220+ is a limited-edition, performance-enhanced version of
the Joulescope JS220.  The JS220+ achieves ±1 nanoamp accuracy with
exceptional temperature stability, all while providing the same best-in-class
high-dynamic current range measurement as the standard JS220.

The [Joulescope JS220+ User's Guide](guide/index.md) describes the
JS220+ improvements, and the
[Joulescope JS220 User's Guide](../js220/guide/index.md) describes how to
use the instrument.  The specification values are also available as
[js220plus_datasheet.yaml](site:products/js220plus/js220plus_datasheet.yaml),
which holds the differences from
[js220_datasheet.yaml](site:products/js220/js220_datasheet.yaml).
